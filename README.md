# 짬짬이 쉼

수업 전 1~5분, 들뜬 반을 차분하게 만드는 전자칠판용 쉼 활동입니다.
유형과 시간을 고르고 시작을 누르면, **그 뒤로 선생님은 아무것도 누르지 않습니다.**
화면이 호흡 안내·소리·상상 문구를 스스로 진행하고 정한 시간에 끝납니다.

👉 **https://shway81-droid.github.io/jjam-rest/**

## 왜 만들었나

체육·점심 직후의 교실을 가라앉히는 데는 수업 시간이 듭니다.
"조용히 하세요"를 반복하는 것 말고는 마땅한 도구가 없고, 명상·호흡 앱은
어른용이거나 로그인·유료·영어라서 교실에서 바로 쓰기 어렵습니다.

짬짬이 가족(게임·퀴즈·영상·이야기)은 모두 에너지를 올리거나 유지하는 활동입니다.
**쉼은 유일하게 에너지를 내리는 활동**이고, 유일하게 교사도 손을 떼고 함께 쉬는 활동입니다.

## 무엇이 들어 있나

쉼 유형 5종, 모두 16편입니다. 각 편은 1·3·5분 중 어느 시간으로도 진행됩니다.

| 유형 | 하는 일 |
|---|---|
| 🫁 숨 고르기 | 커졌다 작아지는 원, 네모를 도는 점을 따라 숨쉬기 (4-6 호흡·상자 호흡·손가락 산 오르기) |
| 🌧 소리 여행 | 눈을 감고 빗소리·파도·모닥불 소리만 듣기 |
| 🎈 상상 여행 | 구름 위·숲속 오솔길·잔잔한 호수를 한 문장씩 따라가기 |
| 🧊 몸 힘 빼기 | 앉은 채로 주먹·어깨·얼굴에 힘을 꽉 주었다 스르르 빼기 |
| 💗 마음 보기 | 오늘 고마웠던 것, 지금 내 기분, 작은 친절 하나 떠올리기 |

## 쓰는 법

1. 유형 카드를 고릅니다 (편은 자동으로 뽑히고, 최근 쓴 편은 피합니다)
2. 1·3·5분 중 하나를 고르고 **시작**을 누릅니다
3. 끝날 때까지 아무것도 누르지 않습니다 — 구석에 **일시정지**(교내 방송)와
   **다음 단계**(문구를 먼저 넘기고 싶을 때) 두 개만 있고, 둘 다 안 눌러도 끝납니다

문구는 **목소리로도 읽어 줍니다.** 눈을 감고 하는 활동이라 화면 글자를 볼 수 없기
때문입니다. 시간을 고르는 화면에서 `읽어줘요` / `글자만` 중에 고를 수 있고,
기기에 한국어 목소리가 없으면 이 선택지 자체가 나타나지 않습니다.
목소리가 둘 이상이면 **어느 목소리로 읽을지 고르고 미리 들어볼 수 있습니다** —
윈도우에는 보통 오래된 기본 목소리와 자연스러운 신경망 목소리가 함께 있어,
어느 쪽으로 들리는지가 활동의 인상을 크게 좌우합니다.

브라우저 목소리는 기기마다 천차만별입니다. 신경망 한국어 목소리(SunHi·InJoon)는
Edge 에만 노출되어, 같은 컴퓨터라도 크롬에서는 오래된 기본 목소리(Heami)만 잡힙니다.
어느 브라우저에서나 같은 목소리로 읽히길 원하면 **짬짬이 목소리를 받으면 됩니다**
(설정 화면의 `또렷한 목소리 받기`, 47MB). 받은 뒤에는 브라우저와 무관하게 같은
소리가 나고, 오프라인에서도 그대로 납니다. 받지 않으면 지금처럼 브라우저 목소리를
쓰고, 자연스러운 목소리가 하나도 없는 기기에는 Edge 를 한 줄로 안내합니다.

소리를 꺼도 전 과정이 진행됩니다. 스피커가 고장 났거나 음소거해야 하는 교실에서도
화면의 문구와 호흡 안내만으로 활동이 완결됩니다.

## 만들어진 방식

- **소리에 음원 파일이 없습니다.** 빗소리·파도·바람·모닥불을 모두 Web Audio로 합성합니다
  (필터를 거친 노이즈, 느린 LFO). 저작권 문제가 없고, 용량이 0이며, 오프라인에서도
  똑같이 나고, 길이 제한이 없습니다.
- **목소리도 녹음 파일이 아닙니다.** 브라우저에 이미 들어 있는 음성합성(Web Speech API)이
  `sessions.json`의 문구를 그대로 읽습니다. 문구를 고쳐도 다시 녹음할 일이 없고, 용량은
  역시 0입니다. 한국어 목소리가 없는 기기에서는 통째로 꺼집니다 — 영어 목소리에 한글을
  넘기면 글자를 하나씩 영어식으로 읽어 알아들을 수 없는 소리가 나기 때문입니다.
  말하는 동안에는 배경음이 뒤로 물러납니다(`js/sound.js`의 `duck`).
  목소리 고르기의 기본값은 **자연스러운 쪽**입니다. 기기에 설치된 목소리를 먼저 고르면
  오프라인에는 안전하지만, 윈도우의 기본 한국어(혜미)는 십수 년 된 연결합성이라
  기계처럼 들립니다. 그래서 신경망 계열을 기본으로 두고, 네트워크 목소리가 실패하면
  (오프라인 교실) 기기 목소리로 자동으로 되돌립니다.
- **짬짬이 목소리는 브라우저 안에서 만들어집니다.** 메타의 MMS 한국어 모델을
  onnxruntime-web 으로 돌립니다 — 문구가 서버로 나가지 않고, 한 번 받으면 오프라인에서도
  같습니다. 모델이 한글이 아니라 로마자를 받으므로 `js/hangul-roman.js` 가 변환하는데,
  표기가 모델이 배운 uroman 과 한 글자라도 어긋나면 발음이 무너집니다. 그래서 자모 표를
  uroman 으로 뽑아 한글 음절 11,172자 전부와 대조했고, `scripts/check-roman.mjs` 가
  CI 에서 같은 검사를 합니다.
- **합성이 느려서 미리 만들어 둡니다.** 이 모델은 단일 스레드 wasm 에서 실시간의 약
  두 배가 걸립니다(6초 문장에 12초). 그래서 말할 때 만들지 않고, 편이 정해지는 순간과
  각 단계가 흐르는 동안 다음 문구를 미리 만듭니다(`js/app.js` 의 `primeAhead`).
  추론은 워커로 보냅니다 — 메인 스레드에서 돌리면 그 십여 초 동안 호흡 애니메이션이
  얼어붙고 일시정지 단추도 눌리지 않습니다.
- **호흡 라벨은 CSS가 아니라 JS 타이머가 바꿉니다.** `prefers-reduced-motion`이 켜진
  환경에서는 CSS 애니메이션 타임라인이 멈춰 라벨 교대까지 정지하기 때문입니다.
  움직임은 CSS(멈춰도 됨), 진행 안내는 JS(항상 동작)로 나눴습니다.
- **콘텐츠는 `data/sessions.json` 한 파일**이 단일 소스입니다. 화면은 그것을 재생만 합니다.
  시간 모드에 맞춰 단계를 자르고 반복하는 규칙은 `js/app.js`의 `buildTimeline`에 있습니다.

### 안전 기준

- 종교적 표현·기도·만트라 없음
- 수면 유도·최면형 문구 없음 (`잠이 듭니다` ✗ → `몸이 편안해집니다` ○)
- 무섭거나 슬픈 상상 소재 없음
- 빠른 점멸·급격한 화면 전환 없음 — 느린 애니메이션만 (광과민성 발작 예방)
- `prefers-reduced-motion`에서는 크기·이동 애니메이션이 멈추고 글자의 느린 페이드만 남습니다

이 기준은 사람 검토에만 맡기지 않고 `scripts/validate-data.mjs`가 CI에서 문구를 검사합니다.

## 개발

빌드 단계가 없는 정적 사이트입니다.

```bash
npx http-server . -p 8378 -c-1
```

검증 (CI와 같은 게이트):

```bash
npm run verify
```

- `scripts/validate-data.mjs` — `sessions.json`이 `js/app.js`의 화면 상수(유형·시간·애니메이션·소리 키)와
  맞는지, 안전 기준 문구를 지켰는지 검사합니다. 상수를 앱 코드에서 직접 읽어 오므로
  데이터와 화면이 따로 노는 상황을 잡습니다.
- `scripts/check-font-coverage.mjs` — 새 문구에 웹폰트 서브셋에 없는 글자가 들어왔는지 봅니다.
- `scripts/check-roman.mjs` — 한글→로마자 변환이 uroman 과 같은지(고정 표본 대조),
  그리고 모든 쉼 문구가 짬짬이 목소리로 읽을 수 있는 모양이 되는지 검사합니다.

공통 파일(자매 사이트 바로가기·웹폰트)은 **jjam이 상류**입니다.

```bash
npm run sync:shared
```

아이콘은 `favicon.svg` 한 파일이 단일 소스입니다. PNG는 `npm run icons`로 생성합니다.
